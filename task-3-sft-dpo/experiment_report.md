# Task 3 实验观察

本实验以 Qwen2.5-0.5B 为基座，在 `q_proj`、`v_proj` 上手写注入 LoRA，rank=8、alpha=16。可训练参数为 540,672，仅占总参数的 0.109%；Qwen chat template 只让 assistant 内容参与损失，mock 多轮对话的 mask 比例为 0.556。SFT 使用 30,000 条 MOSS 中英对话，batch size=4、梯度累积=4、最大长度=512，共优化 1,875 步，用时 1,344 秒；loss 从 1.1348 降至 1.0508，最后 100 步均值为 1.1028。

DPO 在 SFT LoRA 上继续训练，数据目录共解析出 19,996 对偏好样本，其中 18,949 对在长度截断后仍含有效 assistant 标签并参与优化；beta=0.1、学习率为 5e-5。最终 loss 为 0.0081，整体 reward margin 均值为 20.92，最后 100 步均值为 26.07，正 margin 比例为 59.03%。逐样本 loss 波动较大，说明偏好对的长度和难度差异明显。相同中文指令下，base 会重复英文符号；SFT 已能形成连贯中文回答，DPO 输出仍保持完整，并在安全建议等问题上更直接、结构更清晰。LoRA 参数量、loss masking 与 SFT 检查均通过。
