# Task 2 实验观察

本实验实现了字节级 BPE、RoPE、带 KV cache 的 decoder-only Transformer，以及 greedy、temperature、top-k、top-p 四种采样。最终词表大小为 320，其中包含 64 条实际 merge 规则；模型采用 8 层、8 头、隐藏维度 256，约 639 万参数。验证集困惑度在第 16 轮达到最低值约 28.1，随后训练损失继续下降而验证困惑度回升，显示唐诗小语料上出现过拟合。自检测得困惑度 28.16，低于 50 的通过线；KV cache 与全量前向的最大 logits 误差为 2.38e-6。

为改善旧样例中的机械重复和替换字符，生成接口增加了 repetition penalty 与 no-repeat n-gram 约束，并固定随机种子以便复现；四种采样均重新生成并保存。新样例不再出现连续“行行行”式循环或替换字符，但受限于约 49KB 的唐诗小语料，长文本仍会出现生僻字和语义跳跃。另实际尝试把词表扩大到 1024 并重新训练 27 轮，其最佳验证困惑度为 240.48，显著差于原模型，因此没有用较差检查点覆盖最终结果。后续质量提升应优先扩充和清洗语料，而不是只扩大词表。
