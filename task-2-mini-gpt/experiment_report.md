# Task 2 实验观察

本实验从 `chinese-poetry` 的全唐诗 JSON 中抽取并严格清洗 20,000 首候选诗，删除校注、卷号等非诗歌正文，以全文和完整首句双重去重，再按整首诗固定随机种子划分为训练 15,745、验证 1,968、测试 1,968 首。最终模型采用 8 层、8 头、隐藏维度 256、上下文 256，共 6,572,544 个参数。词表保留 byte fallback，同时加入 512 个高频汉字原子并继续学习 BPE 合并，总词表 1,024；这样既能无损编码生僻字，也避免常用汉字被拆成共享字节。

训练在第 19 轮早停，最佳检查点位于第 15 轮；自检 dev token PPL 为 46.70，低于唐诗路线 50 的阈值，UTF-8 byte NLL 为 1.5952。不同词表的 token PPL 不再直接横向比较，只记录字节归一化指标。KV cache 与全量前向最大误差为 3.81e-6。

M5 使用 10 个不出现在 train/dev 的完整测试集首句，分别运行 greedy、temperature、top-k、top-p。生成关闭字节级重复惩罚，采用严格 UTF-8 合法性和完整字符边界，并在第一条新诗句结束时停止；40 条原始 token、字节、参数和种子全部保存。人工逐条检查后 32/40 同时满足可读、主题基本连续、无机械重复，四策略分别通过 8、9、7、8 条。其余 8 条的语病或重复也保留在复核文件中，说明小模型仍有提升空间，但已能稳定生成短篇可读唐诗式续句。
