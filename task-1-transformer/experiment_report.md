# Task 1 实验观察

本实验使用训练集构建字符级词表，不加载预训练模型。分类器包含 4 层 Transformer encoder、4 个注意力头，隐藏维度为 128，参数量约 126 万。训练 8 轮后，最佳验证集准确率为 0.9000，出现在第 6 轮，高于 0.80 通过线及 0.85 参考基线。训练准确率最终升至 0.9714，而验证准确率在 0.90 附近趋于稳定；第 4 轮后验证损失开始升高，说明模型已经出现轻微过拟合，后续可尝试增大 dropout 或更早停止。

最后一层第 0 个注意力头的热图显示，负面物流样本对“订单处理速度”“发货”等位置响应较强；长句样本更多关注“结婚证”“身份证”“地址”等决定语义的词。正面样本被误判为负面，其文本同时包含“房间太小”“点心不太好吃”等明显负向描述，表明单一总体标签与句内多方面评价存在冲突。手写 attention 与 PyTorch 参考实现的最大误差为 7.15e-7，causal mask 的未来信息泄漏为 0。
